# 8. Словник термінів

## Робототехніка

| English | Українською | Пояснення |
| --- | --- | --- |
| robot | робот | Машина, яка сприймає світ, обробляє інформацію і діє |
| sensor | датчик, сенсор | Пристрій, що вимірює щось у навколишньому світі |
| distance sensor | датчик відстані | Вимірює відстань до найближчої перешкоди |
| actuator | актуатор, виконавчий механізм | Пристрій, що виконує дію: двигун, захват, світлодіод |
| motor | двигун | Перетворює електричну енергію на рух |
| controller | контролер | Програма (або пристрій), що керує роботом |
| firmware | прошивка | Програма, вбудована в пристрій |
| autonomous | автономний | Такий, що працює без постійного керування людиною |
| Sense → Think → Act | сприйняття → обробка → дія | Базова схема роботи будь-якого робота |
| simulation | симуляція | Відтворення робота і середовища на комп'ютері |
| simulator | симулятор | Програма для симуляції |
| digital twin | цифровий двійник | Віртуальна копія реального об'єкта, пов'язана з ним даними |
| sim-to-real gap | розрив між симуляцією і реальністю | Відмінність між поведінкою робота в симуляції і в реальності |
| RPA (Robotic Process Automation) | роботизована автоматизація процесів | Програмні «роботи», що автоматизують офісну роботу з даними |

## Інтерфейс Webots

| English | Українською | Пояснення |
| --- | --- | --- |
| world | світ | Файл `.wbt` з описом усієї симуляції |
| project directory | папка проєкту | Папка з підпапками `worlds`, `controllers`, `protos` тощо |
| 3D view | 3D-вікно | Тривимірне зображення світу |
| Scene Tree | дерево сцени | Ієрархічний список усіх об'єктів світу |
| node | вузол | Об'єкт у дереві сцени |
| field | поле | Властивість вузла |
| PROTO | PROTO, шаблон | Готовий шаблон об'єкта, який можна додати у світ |
| Text Editor | текстовий редактор | Вікно для редагування програм |
| Console | консоль | Вікно повідомлень і помилок |
| Add | додати | Кнопка додавання нового вузла |
| Pause | пауза | Зупинити симуляцію |
| Step | крок | Виконати один крок симуляції |
| Real-time | реальний час | Запустити симуляцію зі звичайною швидкістю |
| Fast | швидко | Запустити симуляцію якнайшвидше |
| Reset Simulation | скинути симуляцію | Повернути світ до початкового стану |
| Reload World | перезавантажити світ | Відкрити світ заново із збереженого файлу |
| Save World | зберегти світ | Записати світ у файл |
| Preferences | налаштування | Параметри програми |
| translation | переміщення, положення | Поле з координатами об'єкта (x, y, z) |
| rotation | поворот | Поле з орієнтацією об'єкта |
| size | розмір | Поле з розмірами об'єкта |
| viewpoint | точка огляду | Положення камери, через яку ви дивитеся на світ |
| Guided Tour | екскурсія | Демонстрація можливостей Webots |
