# 6. Від симуляції до реального світу

## Що ми насправді щойно побачили

Віртуальний e-puck працює за тією самою схемою **сприйняття → обробка → дія**, що й справжні роботи:

| Етап | e-puck у Webots | Справжні роботи |
| --- | --- | --- |
| **Сприйняття** | 8 інфрачервоних датчиків відстані | лідари складських роботів, ультразвукові датчики паркування в автомобілях, датчики робота-пилососа |
| **Обробка** | контролер `e-puck_avoid_obstacles` | бортовий комп'ютер з програмою |
| **Дія** | два колісні двигуни, світлодіоди | двигуни коліс, сигнальні вогні, звукові сигнали |

Алгоритм «їдь уперед, а якщо попереду перешкода, повертай» лежить в основі роботи робота-пилососа. Складні роботи на складах і безпілотні автомобілі використовують ту саму ідею, тільки з набагато більшою кількістю датчиків і розумнішою обробкою даних.

## Де симуляцію використовують у промисловості

* **Логістика**: моделюють, як сотні роботів рухаються складом, щоб вони не заважали один одному.
* **Автомобілебудування**: налаштовують роботизовані лінії складання до того, як побудовано завод.
* **Безпілотний транспорт**: перевіряють небезпечні ситуації на дорозі, які неможливо відтворити в реальності.
* **Сільське господарство**: тестують маршрути автономних тракторів і дронів-обприскувачів.
* **Гуманітарне розмінування**: Україна сьогодні одна з найбільш замінованих країн світу. Алгоритми керування роботами-саперами можна відпрацювати в симуляції без ризику для людей і техніки.

## Як ви можете використати ці знання

Знання з цього курсу стосуються не лише інженерів-робототехніків. Вони корисні й операторові з обробки інформації:

| Напрям | Як пов'язано з курсом |
| --- | --- |
| **Оператор робототехнічних систем** | Розуміння, як робот сприймає світ і як ним керувати |
| **Тестування програмного забезпечення (QA)** | Запуск сценаріїв у симуляторі, пошук і опис помилок |
| **Обробка даних** | Роботи генерують величезні обсяги даних з датчиків. Їх треба збирати, впорядковувати, розмічати (наприклад, позначати об'єкти на зображеннях для навчання штучного інтелекту) |
| **Автоматизація офісних процесів (RPA)** | Той самий принцип «вхідні дані → обробка → дія», тільки для документів і таблиць |
| **Програмування** | Наступний крок: написати власний контролер мовою Python |
